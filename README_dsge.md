# Modelos Estocásticos Dinámicos (DSGE)

Trabajos de **Modelos DSGE / Macroeconomía Dinámica** — Maestría en Economía, Universidad de San Andrés (2026).

## Contenido

Resoluciones de la serie de *homeworks* del curso e informe final, con implementación numérica en MATLAB/Dynare.

- **Homework 01** — Modelo de Solow
- **Homework 02** — Generaciones solapadas (OLG)
- **Homework 03** — Métodos variacionales *(incluye implementación en MATLAB/Dynare: steady state e impulso-respuesta)*
- **Homework 04** — RBC básico
- **Homework 05** — Método lineal-cuadrático
- **Homework 06** — Método matricial-cuadrático
- **Homework 07** — Modelo con bancos
- **Homework 08** — Economía pequeña y abierta (SOE)
- **Informe final** — modelo estocástico dinámico aplicado

## Herramientas

MATLAB · Dynare · LaTeX
